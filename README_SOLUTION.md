🌦️ Weather App – Frontend Mentor Challenge

📌 Overview

This project is a responsive weather application built as part of a Frontend Mentor
 challenge. It displays current weather data and allows users to search for locations with real-time suggestions. The design is mobile-first and scales smoothly from 320px up to 1440px.

🛠️ Tech Stack

React.js – Component-based UI development

Tailwind CSS – Utility-first styling with responsive design patterns

Weather API – For real-time weather data

React Router (useSearchParams) – Managing search queries in the URL

🚀 Features

✅ Fully responsive design (320px → 1440px)
✅ Search functionality with live suggestions
✅ Dynamic data updates across the entire app
✅ Grid layout for structured and modern UI
✅ Custom Tailwind background patterns for a clean look
✅ Reusable components to keep code modular and maintainable
✅ Mobile-first workflow ensuring accessibility on all devices

📚 What I Learned

This project was a huge learning experience for me. Some of the key takeaways include:

Building a mobile-first responsive design that adapts from 320px to 1440px

Implementing a fully working search functionality with autocomplete suggestions

Learning to dynamically update data across the app when the search changes

Creating grid-based layouts for better structure and alignment

Using React Router’s useSearchParams hook to sync search queries with the URL

Practicing Tailwind CSS advanced features like custom backgrounds and responsive utilities

Writing clean, reusable React components for scalability

Strengthening my understanding of state management & props flow in React


💡 Improvements for the Future

Enhance error handling for invalid city searches

Add unit conversion (°C ↔ °F)
